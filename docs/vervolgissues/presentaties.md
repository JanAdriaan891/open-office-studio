# Presentaties: twee PPTX-routes vergelijken en editor kiezen

Onderdeel van #1. Zie `docs/onderzoek/landschap.md` voor de broninventarisatie.

Vergelijk een browser/WASM-editor en een volledige suite op bestaande presentaties voordat de engine definitief wordt gekozen.

## Acceptatiecriteria

- [ ] Gevallen P1–P3 uitvoeren: openen, één wijziging, opslaan en heropenen.
- [ ] Masters, thema’s, notities, animaties en onbekende onderdelen controleren.
- [ ] Geen generatiebibliotheek zonder import als complete bewerkingsroute presenteren.
- [ ] Keuze met pakketversie, licentie, bundelomvang en beperkingen vastleggen.
